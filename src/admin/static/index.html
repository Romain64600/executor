Les deux pages · The two pages

Validation & Submit — la page principale (« ajout des prix ») : extraire un feed marchand, matcher les jeux, valider le rapport, puis soumettre les offres.

The main page (“price entry”): extract a merchant feed, match games, validate the report, then submit the offers.

Tri des listes · Sort lists — déplacer les offres non-jeu vers leurs listes cibles (Softwares, Gift cards, Blacklist…), en lot rapide (Batché) ou différé par store.

Move non-game offers into their target lists (Softwares, Gift cards, Blacklist…), as a fast batch (Batché) or a per-store deferred run.

Naviguer · Navigate

En haut, le lien Tri des listes → ouvre la console de tri ; depuis celle-ci, l'onglet Validation & Submit revient ici (la page principale).

Top bar, the Tri des listes → link opens the sort console; from there, the Validation & Submit tab comes back here (the main page).

Le déroulé · The workflow

1. Extraire une page du feed → 2. Matcher → 3. Valider → 4. Soumettre (canary d'abord, puis le lot). Tri : Nouveau scan → Canary → Batch. Option Différé = une seule vérif par store (plus rapide sur un gros feed).

1. Extract a feed page → 2. Match → 3. Validate → 4. Submit (canary first, then the batch). Sort: New scan → Canary → Batch. Deferred = one verify per store (faster on a big feed).
