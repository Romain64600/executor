📖 Data Entry Auto — Aide / Help

Ce que fait ce mode · What it does

Pour chaque marchand, il balaie le feed page par page : extraire → matcher → ajouter automatiquement TOUTES les offres candidates (sans validation humaine) → page suivante. Par défaut il s'arrête aux 30 pages les moins profondes (l'index submit n'est productif que là) : sur un feed plus long le run finit « TERMINÉ — couverture partielle » (la fin non balayée est notée dans le recap) ; monte « Max pages » pour un balayage profond. Il tient un recap détaillé.

For each merchant it sweeps the feed page by page: extract → match → auto-add EVERY candidate (no human validation) → next page. By default it stops after the 30 shallowest pages (where the submit index is productive): a deeper feed ends “TERMINÉ — couverture partielle” with the unswept tail noted in the recap; raise “Max pages” for a deep sweep. It keeps a detailed recap.

Sécurité · Safety

Le matcher est le filtre : il écarte déjà console / sans page AKS / ambigu. Tu audites le recap et supprimes les erreurs après. Un blocage (feed illisible, session tombée) arrête tout (fail-closed) — jamais de reconnexion automatique.

The matcher is the gate (it drops console / no-AKS-page / ambiguous). You audit the recap and delete mistakes afterwards. Any block (feed unreadable, dropped session) HALTS everything (fail-closed) — never an auto re-login.

Seuls les marchands vettés sont proposés ; le serveur refuse tout autre marchand même par requête directe (allowlist autoritaire). Difmark (parké) et Gameboost sont exclus pour le moment.

Only vetted merchants are offered; the server refuses any other merchant even via a hand-crafted request (authoritative allowlist). Difmark (parked) and Gameboost are excluded for now.
