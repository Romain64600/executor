Ce que fait ce mode · What it does

Tu colles une liste d'URLs de pages AKS (une par ligne, ex. …/buy-the-sinking-city-2-cd-key-compare-prices/). Pour chaque jeu, le mode épingle cette page AKS, puis trouve les offres marchandes à saisir en pilotant la recherche du feed (par titre et par URL) sur tous les marchands vettés, et planifie chaque offre via la même logique de match (games-only, blacklist régions, région/édition) sur la page épinglée.

Paste a list of AKS page URLs (one per line). For each game it pins that AKS page, finds the pending merchant offers via the feed SEARCH (by name and by URL) across every vetted merchant, and plans each through the same match logic against the pinned page.

Dry-run d'abord · Dry-run first

Cet aperçu est 100 % lecture seule : il résout, cherche, planifie et affiche ce qui serait saisi (offre, région/édition) — sans rien écrire. La saisie réelle sera une étape séparée et explicitement confirmée. Une session tombée arrête tout (fail-closed) — jamais de reconnexion automatique.

This preview is READ-ONLY: it resolves, searches, plans and shows what WOULD be entered — no writes. Actual entry is a separate, explicitly-confirmed step. A dropped session HALTS everything (fail-closed) — never an auto re-login.
