Ce que montre la page · What it shows

Une carte par machine de l'exécuteur : UP / DOWN (DOWN = injoignable, admin qui ne répond pas, ou un service clé arrêté — le motif est écrit), la tâche en cours en clair (balayage, groupe, boucle, passe, marchand, page, étape), les offres créées, la version du code, la charge, les alertes en rouge et les 20 derniers événements du journal. Rafraîchi toutes les 15 s.

One card per executor machine: UP / DOWN (with the reason), the current task in plain words, created offers, code version, load, alerts in red and the last 20 log events. Refreshed every 15 s.

Lecture seule · Read-only

Cette page ne pilote rien : aucun bouton ne lance ni n'arrête quoi que ce soit. Pour agir sur une machine, « Ouvrir la console » mène à SA console. Les autres machines sont lues par ssh avec une clé dédiée qui ne sait faire qu'une chose : prendre la photo (ops/VUE_D_ENSEMBLE.md).

This page drives nothing. To act on a machine, open its own console. Remote machines are read over ssh with a dedicated key restricted to the snapshot command.
