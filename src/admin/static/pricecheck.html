📖 Price check — Aide / Help

Ce que montre cette pageWhat it shows

Le moniteur price-check (service price-check, dépôt à part) contrôle les premiers prix (les 3 premiers de chaque édition) de chaque page AllKeyShop suivie : le top 10 Popular, le top 5 Coming soon PC (Price check top) et tous les jeux des tops clicks de la home (Price check homepage). Il alerte sur Discord quand cette offre ne correspond pas au produit ou au marché : autre produit, autre région, autre plateforme, compte vendu comme clé, DLC vendu comme le jeu, autre édition.

Chaque carte est un report : l'offre, le verdict, la raison, la page AllKeyShop et l'URL du marchand. SUSPECT = alerte envoyée ; À VÉRIFIER = le nom n'est lisible ni dans l'URL ni sur la page, mais l'offre est le premier prix d'une page d'un top ou d'un coming soon (alerte envoyée) ; NON VÉRIFIABLE = même cas ailleurs, noté sans alerte. La pastille TOP ou HOMEPAGE dit d'où vient le report : TOP quand la page est dans les tops en ce moment (elle est aussi dans le TOP 50 de la homepage), HOMEPAGE sinon ; une page sortie des listes garde le mode qui l'a contrôlée. Le filtre Mode sépare les deux. La pastille PREMIER PRIX marque une offre parmi les 3 offres de clé les moins chères de son édition : un SUSPECT sur un premier prix est une urgence, envoyée sur le salon Discord des urgences premiers prix. Chaque alerte a aussi son fil Discord (lien sur la carte) : on peut y trancher en répondant « vrai », « faux » ou « à discuter » + une note ; la décision arrive ici, signée « (Discord) ».

Pour toute l'équipe : le guide de l'équipe (français et anglais) explique les trois salons Discord, la lecture d'une alerte, le feedback dans le fil de l'alerte et ce que fait le moniteur.

For the whole team: the team guide (French and English) explains the three Discord channels, reading an alert, feedback in the alert's thread and what the monitor does.

The price-check monitor checks the first offer of every followed AllKeyShop page and alerts on Discord when it does not match the product or the market. Each card is one report: offer, verdict, reason, AllKeyShop page and merchant URL.

TrancherDeciding

Vrai positif : l'erreur est réelle, l'alerte était juste. Faux positif : l'offre est correcte, l'alerte n'aurait pas dû partir. À discuter : on en parle. D'accord avec l'erreur décrite sur le report : pas de note, il n'y a rien à commenter. Sinon, la note dit pourquoi (ex. « la page AKS est bien DLC ») ; c'est elle qui sert à corriger les règles du moniteur. La note part avec le clic sur la décision ; tapée après coup, elle s'enregistre avec Entrée ou Enregistrer la note (une note pas encore enregistrée est signalée sur sa carte).

La décision s'ajoute à decisions.jsonl, signée de ton identifiant de connexion ; le moniteur la relit avant son passage suivant. Une nouvelle décision sur la même offre remplace la précédente (l'historique reste). Rien n'est envoyé, aucune offre AllKeyShop n'est modifiée.

True / false positive / to discuss. Agree with the error described: no note needed; otherwise a note says why: it leaves with the click on the decision; typed afterwards, press Enter or « Enregistrer la note ». The decision is appended to decisions.jsonl under your login; the monitor re-reads it before its next pass. A later decision on the same offer replaces the earlier one. Nothing is sent, no AllKeyShop offer is changed.

Lancer un passageRunning a pass

Le moniteur passe seul toutes les 2 min 30 sur les top games et toutes les 15 min sur la homepage. Les deux boutons Lancer le price check top et Lancer le price check homepage déclenchent un passage tout de suite, qui recontrôle toutes les offres retenues de ses pages, déjà vues ou non (sauf les faux positifs tranchés) : une offre signalée trouvée OK devient réparée si l'offre a changé (URL, région, plateforme, édition) ou a quitté sa page, et faux positif levé si rien n'a changé (c'est une règle ajoutée depuis qui la blanchit), et vérifiée OK si elle n'avait pas pu être vérifiée ; une offre encore sur sa page mais « sans prix » n'est pas réparée ; une offre OK trouvée en erreur est une nouvelle alerte. Un récapitulatif part sur Discord, nouvelles erreurs en tête. Le passage homepage complet est long (2 466 offres en 2 h 30 le 02/10/2026 ; les top games continuent de passer pendant ce temps). En automatique, les offres signalées sont recontrôlées une fois par heure. Le passage : la demande est déposée dans le dossier partagé, le moniteur la lit dans les secondes qui viennent. Le bouton est grisé pendant le passage du mode ou quand une demande attend ; l'état (en cours, avancement, dernier et prochain passage) se rafraîchit toutes les 10 s. Un passage automatique ne contrôle que les offres jamais vues (et, une fois par heure, les offres signalées) : « aucune nouvelle offre à contrôler » est le cas normal quand les premiers prix n'ont pas changé.

The monitor runs on its own; the two buttons ask it to run a mode now. The request is a file in the shared directory, read by the monitor within seconds. The button is disabled while that mode is running or a request is pending.

FraîcheurFreshness

Le moniteur réécrit les reports à chaque passage. Si l'export a plus de 45 minutes, la page le signale : le service est peut-être arrêté. Une offre qui n'est plus le premier prix depuis plus d'une heure porte la mention « Plus vu en premier prix » ; la case « encore en tête seulement » la masque. Un lien …/executor/price-check#offer-<id> ouvre la page sur un seul report.

The monitor rewrites the reports after every pass; an export older than 45 minutes is flagged. An offer no longer first price for over an hour is marked; « encore en tête seulement » hides it. #offer-<id> opens one report.

Green when AllKeyShop is cheaper, orange at the same price, red when the competitor is cheaper. Reports

Comment trancher un reportHow to decide a report

D'accord avec l'erreur décrite sur le report ? Clique Vrai positif, sans note : il n'y a rien à commenter. La note sert seulement à dire pourquoi tu n'es pas d'accord, ou à préciser.

  1. Lis la raison : ce que le moniteur a trouvé.
  2. Vérifie les deux pages : « Page AllKeyShop » (édition, région et son nom de filtre, plateforme) et « Offre marchand » (ce qui est vraiment vendu).
  3. ① Pourquoi ? Seulement si besoin : pour un Faux positif, un À discuter ou une précision, écris en une phrase ce que tu as vu, par exemple « la fiche du marchand dit ROW ». D'accord avec l'erreur décrite : rien à écrire.
  4. ② Ta décision : Vrai positif (l'erreur est réelle), Faux positif (l'offre est correcte) ou À discuter. La note part avec le clic, s'il y en a une.

À discuter : le report passe dans la partie « 💬 À discuter », en tête de la liste, avec ta note comme commentaire, jusqu'à la décision finale. Pour clore, tranche sur l'offre, pas sur le commentaire : Vrai positif si l'erreur est réelle, Faux positif si l'offre est correcte (par exemple quand un commentaire montre que la région est juste).

Après coup : modifie la note, puis « Mettre à jour la note » (ou Entrée ; Maj+Entrée pour aller à la ligne). Une note pas encore enregistrée est signalée en orange, et la page prévient avant de se fermer. Tout est expliqué dans le guide de l'équipe.

Agree with the error described on the report? Click True, no note: there is nothing to comment. The note is only for saying why you disagree, or for a detail.

  1. Read the reason: what the monitor found.
  2. Check both pages: « AllKeyShop page » (edition, region and its filter name, platform) and « Merchant offer » (what is really sold).
  3. ① Why? Only if needed: for a False positive, a To discuss or a detail, write in one sentence what you saw, for instance « the merchant's page says ROW ». Agree with the error described: nothing to write.
  4. ② Your decision: True (the error is real), False positive (the offer is right) or To discuss. The note leaves with the click, if there is one.

To discuss: the report moves to the « 💬 To discuss » part, at the top of the list, with your note as a comment, until the final decision. To close it, decide on the offer, not on the comment: True if the error is real, False positive if the offer is right (for instance when a comment shows the region is right).

Afterwards: edit the note, then « Update the note » (or Enter; Shift+Enter for a new line). A note not saved yet is flagged in orange, and the page warns before closing. Everything is in the team guide.
